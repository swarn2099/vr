The problem

AI made writing code fast.
Understanding still starts over — every session.

Every AI session begins at zero

Before touching Spend Management, an engineer or AI agent must rediscover what exists, what it means, what depends on it, and why it was built that way. That work is redone for every session, every engineer, every model.

Confident ≠ correct

A coding agent will implement “let users edit card controls in read-only mode” fluently and quickly — it has no way to know a person already decided read-only must stay read-only.

In a bank, that’s not a productivity gap — it’s a control gap

Product decisions live in people’s heads and old tickets. When AI regenerates code faster than humans can review it, undocumented intent is the first casualty — and the compliance function becomes the bottleneck.

AI accelerates execution.
Understanding — and governance — start over.

What VR is

Copilot, but it remembers your product —
and remembers who decided what.

  • Product graph: 7,800+ nodes connecting capabilities → behavior → implementation → evidence → tests → integrations → human decisions, for the real Spend Management estate.
  • Works inside Copilot: engineers ask normal questions; VR supplies bounded, cited context and validates every claim mechanically.
  • Governance built in: human decisions are first-class records with a named reviewer and an append-only audit history.
A plain coding agent reconstructs the product.
VR remembers it.
Every fact is labeled by how it is known

EXISTS TODAY backed by direct code evidence

INFERRED supported interpretation, not reviewed

RULE TO PROTECT a named person approved it

UNKNOWN VR says so — it never guesses

The core principle: confidence is never authority

No model output — however confident — becomes a product rule. Only an explicit human decision does. And once decided, no AI can silently undo it.

How it works

Four steps, and only one of them needs a person

1 · Learn the productVR reads the estate once and builds a memory: capabilities, behavior, evidence, and what it could not determine
→
2 · Answer with citationsEvery question answered from that memory — with file and line references, and honest unknowns
→
3 · Draft the rulesOne command turns a capability into a reviewable draft of what it does today. Nothing invented
→
4 · A person decidesOnly a named human turns behavior into a rule. This is the step AI is not allowed to take
The AI proposes. VR checks.

Copilot does the reasoning; VR supplies the evidence and rejects any claim that cites nothing. A confident sentence with no source never reaches the answer.

It says when it doesn't know

“Should we enhance MCC from 23 to 43?” → VR asks what 23 → 43 means, and stops. In a bank, a confident wrong answer costs more than no answer.

It runs where the code is

Inside VS Code, on the Copilot licenses engineers already have. No code, data, or decisions leave the machine.

In a regulated environment, credibility is won by what you decline to promise. VR is built on that principle — it even applies it to its own answers.
